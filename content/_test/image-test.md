## Inline Images

The following is an example of what it looks like when an image gets embedded inside the paragraph. When the text on the page enrobes the photo like chocolate enrobes a chewy nuget center. This is text with an image embedded. ![inline image](/img/riso-blue-blob-400px.svg) Examples of when you might want to use an inline image include posts with photos from a recent trip, placing an image that has a transparent background inside a paragraph to give something the appearance of floating inside the text embedded within the paragraph.
